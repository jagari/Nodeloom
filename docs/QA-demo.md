# 시연 QA 확인표 (`v0.1.0-beta.4`)

시연 장비 그대로 확인한다. 칸에는 `OK`, `실패`(이슈 번호), `-`(해당 없음)를 적는다. 실패하면 증상, 로그 파일, 화면 캡처를 그 영역 주인의 이슈에 댓글로 남긴다. 시연을 막는 문제면 새 이슈를 만들고 주인을 지정한다.

- 마스터·재배정: #35(A 성인진) · 에이전트 재연결·라즈베리파이: #36(B 송종민) · 대시보드 화면: #37(C 이찬용) · 데스크톱 앱·릴리즈: #38(D 황수영)
- 로그 파일: 윈도우 `%LOCALAPPDATA%\nodeloom\logs\desktop.log`, 맥 `~/Library/Application Support/nodeloom/logs/desktop.log`

## 4. 한 대 빼기 (시연 5단계)

작업 중인 참여 기기를 끊는다. 마스터는 끊지 않는다. 시간은 끊은 순간부터 잰다. 아직 시험하지 않은 칸은 빈칸이나 `미확인`으로 둔다.

**필수 검증 (내일 시연 그대로)**

| 끊는 방법 | 끊은 기기 | 재배정까지 | 전체 완료까지 | 작업 Done | "moved from" 표시 | 다시 켰을 때 자동 재접속 |
|---|---|---|---|---|---|---|
| **와이파이 끄기** | | | | | | |

기준: 재배정 **10초 이내**가 목표다. 전체 완료 시간은 따로 기록한다(A 문서의 실기기 기준은 15초 이내). 측정하기 전에는 달성했다고 쓰지 않는다.
