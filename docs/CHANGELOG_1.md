시연 빌드: 갑자기 끊긴 기기와 마스터를 알아차리고, 작업 분배를 화면으로 보여 준다. 설치 방법은 `docs/BETA.md`, 시연 대본은 `docs/DEMO.md`.

### 추가

- 에이전트가 마스터의 응답이 끊긴 것을 알아차린다. 승인 후 1~5초마다 확인 신호(Ping)를 보내고, 3~15초 동안 아무것도 받지 못하면 연결을 끊고 다시 붙는다. 이전에는 마스터가 꺼지면 에이전트가 계속 기다렸다(#36).
- 명령줄 에이전트는 마스터를 못 찾아도 종료하지 않고 찾을 때까지 계속 찾는다. 찾은 마스터에 5번 연속 접속하지 못하면 다시 탐색한다. 공유기가 마스터에 새 주소를 준 경우다(#36).
- 대시보드의 **Demo job** 버튼. 테스트 작업 600프레임을 연결된 기기들에 나눠 보낸다. 기존 입력은 **Custom job** 아래로 옮겼다(#37).
- 작업 카드에 기기별 구간 막대를 보인다. 어느 기기가 어느 구간을 맡아 얼마나 했는지 한눈에 보인다(#37).
- 조각이 다른 기기로 넘어가면 "Moved to another machine: A → B"를 10초 동안 보인다(#37).
- 기기 카드에 그 기기가 지금 맡은 구간과 진행률을 보인다. 없으면 Idle(#37).

## [0.1.0-beta.3] - 2026-11-02

시연 준비: 윈도우 앱 문제를 고치고, 기기 추가를 쉽게 했다. 설치 방법은 `docs/BETA.md`.

### 수정

- 윈도우: 역할을 고르거나 "Pair as a new machine"을 누르면 앱이 다시 시작하지 않고 사라지던 문제. 새 앱이 종료 중인 앱에 넘겨지면서 최대 10초 기다린 뒤 꺼졌다.
- 윈도우: 마스터 기기에서 트레이의 Settings를 누르면 앱이 멈추던 문제. 창을 앱 시작 때 한 번만 만들게 했다.

### 추가

- 대시보드의 **Add a machine** 안내. 순서, 안 보일 때 확인할 것, 직접 입력할 주소(복사 버튼), 명령줄 명령을 보여 준다.
- 참여 기기에서 마스터 주소를 직접 입력할 수 있다(**Enter the address**). 자동 탐색이 막힌 네트워크에서도 붙는다.
- 마스터 API `GET /api/info`. 다른 기기가 붙을 주소를 알려 준다.
- 앱 로그 파일(`nodeloom/logs/desktop.log`). 위치는 앱 설정 화면에 나온다.

## [0.1.0-beta.2] - 2026-10-27

데스크톱 앱이 생겼다. 설치 방법은 `docs/BETA.md`.

### 추가

- 데스크톱 앱(macOS `.dmg`, Windows `.exe`, Linux `.deb`). 설치하고 켜면 끝나고, 터미널이 필요 없다(#33).
  - 처음 실행할 때 역할을 고른다. "Start a cluster here"는 마스터와 이 기기의 에이전트를 앱 안에서 실행하고, 창이 바로 대시보드가 된다. "Join a cluster"는 클러스터를 스스로 찾고 확인 코드를 크게 보여 준다.
  - 트레이에 상주한다. 창을 닫아도 계속 돌고, 로그인할 때 자동으로 시작할 수 있다. 두 번 실행하면 기존 창이 앞으로 나온다.
  - 대시보드에서 제거된 기기는 앱에서 "Pair as a new machine"으로 다시 페어링한다.
- 명령줄 버전과 같은 데이터 폴더를 쓴다. 한 기기에서 어느 쪽으로 실행해도 같은 신원과 승인 목록이다.

### 수정

- Safari(WebKit)에서 대시보드가 "Connecting…"에서 멈추던 문제. 보안 정책(CSP)이 실시간 연결(`ws:`)을 막고 있었다.

## [0.1.0-beta.1] - 2026-10-26

팀 내부 첫 베타. 설치 방법과 알려진 제한은 `docs/BETA.md`.

### 추가

- 기기 한 대가 마스터, 나머지가 에이전트가 되어 한 풀로 묶인다. 같은 네트워크에서는 mDNS로 마스터를 자동으로 찾는다.
- 페어링 승인: 새 기기는 대시보드에서 6자리 코드를 대조해 한 번 승인한다. 이후에는 기기별 서명 키로 자동 재연결한다. 제거한 기기의 키는 영구 거부한다(#22).
- 대시보드: 마스터가 직접 제공하고, `http://<마스터>:7878`을 브라우저로 연다. 처음 실행할 때 출력되는 링크로 열면 관리 토큰을 따로 입력하지 않아도 된다.
- 작업 분산: 테스트 작업(`--enable-fake-runner`)을 기기 수만큼 나눠 보내고, 기기가 빠지면 다른 기기로 다시 보낸다. Blender 렌더도 지원하지만 보류 상태이고 실제 Blender로는 검증하지 않았다.
- 지원 플랫폼: 리눅스 x64·arm64(라즈베리파이·Jetson, 정적 링크), 윈도우 x64·arm64, macOS arm64(#23).
- 설치 스크립트 `install.sh`(macOS·Linux), `install.ps1`(Windows).

### 알려진 제한

- 통신이 암호화되지 않는다(#6). 믿을 수 있는 네트워크에서만 쓴다.
- 부팅할 때 자동으로 실행되지 않는다(#9). 터미널에서 직접 실행한다.
- 실제 작업 플러그인(Whisper 배치 전사, #26)과 작업 파일 전송(#5)은 아직 없다.
- GPU 지표가 없다(#16, #17).
- 서명하지 않은 바이너리라 macOS Gatekeeper·Windows SmartScreen 경고가 나올 수 있다. 설치 스크립트가 다운로드 표시를 지운다.
- 실기기 검증 전이다(#1, #4, #24).
